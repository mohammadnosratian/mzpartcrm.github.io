وب‌سرویس فروش — سایت فروشگاهی

اتصال mz.omdepart.ir و هر فروشگاه (WooCommerce / اختصاصی) به CRM — سفارش، موجودی، مشتری
با POST /auth یا /token با API Key ساخته می‌شود و ۲۴ ساعت معتبر است.
درگاه پرداخت فروشگاه: ریال — نگاشت مبلغ در n8n یا مستقیم.
چطور وصل می‌شود؟ دو مسیر داری:
۱) مستقیم: CRM با GET /orders و PUT /stock فروشگاه را با API Key می‌خواند/به‌روز می‌کند.
۲) از طریق n8n (پیشنهادی): آدرس فروشگاه را در n8n به عنوان HTTP Request قرار بده و آدرس n8n را بالا به عنوان Base URL بگذار؛ سپس نگاشت ریال ↔ تومان و فیلدها داخل n8n انجام می‌شود. وب‌هوک فروشگاه هم می‌تواند سفارش جدید را آنی به /webhook/crm/store-order در n8n بفرستد.
